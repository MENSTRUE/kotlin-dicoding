# 📚 Kotlin Learning Journey: Dasar & OOP (Studi Kasus Dicoding)

Selamat datang di repositori ini! Ini adalah kumpulan kode yang saya buat selama proses belajar bahasa pemrograman Kotlin, khususnya berfokus pada **dasar-dasar Kotlin** dan **konsep Object-Oriented Programming (OOP)**. Sebagian besar materi pembelajaran saya mengikuti kurikulum dan panduan yang disediakan di **Dicoding**, sebuah platform belajar online.

Repositori ini berfungsi sebagai catatan pribadi, tempat praktik, dan referensi cepat untuk sintaksis, konsep fundamental, serta implementasi OOP di Kotlin.

---

## 📄 Daftar File Kotlin

Berikut adalah daftar file `.kt` yang diorganisir berdasarkan topik dan struktur folder di repositori ini. Saya membagi file-file ini menjadi dua kategori besar: **Dasar-Dasar Kotlin** yang berfokus pada sintaksis dan logika fundamental, dan **Konsep Object-Oriented Programming (OOP) Lanjutan** yang berfokus pada cara merancang kode menggunakan kelas, objek, dan prinsip OOP.

### 📌 **Dasar-Dasar Kotlin**

Bagian ini berisi file-file yang berada di root folder `src/` dan mencakup fundamental bahasa Kotlin seperti tipe data, operator, kontrol alur, dan fungsi dasar.

* [`Array.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/Array.kt) - Deklarasi dan manipulasi dasar Array.
* [`Indexing.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/Indexing.kt) - Cara mengakses elemen Array atau String menggunakan indeks.
* [`Int.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/Int.kt) - Contoh penggunaan tipe data Integer.
* [`Main.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/Main.kt) - Titik masuk utama program Kotlin.
* [`anatomi function.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/anatomi%20function.kt) - Struktur dan bagian-bagian dari sebuah fungsi di Kotlin.
* [`and(&&).kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/and(&&).kt) - Contoh penggunaan operator logika `AND` (`&&`).
* [`break and continue.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/break%20and%20continue.kt) - Mengontrol alur perulangan dengan `break` dan `continue`.
* [`char.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/char.kt) - Demonstrasi tipe data Character.
* [`escaped.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/escaped.kt) - (Deskripsi: Mungkin terkait dengan karakter escape atau string escape).
* [`expression & statement.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/expression%20&%20statement.kt) - Perbedaan antara ekspresi dan statement di Kotlin.
* [`for looping.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/for%20looping.kt) - Berbagai cara melakukan perulangan menggunakan `for`.
* [`functions.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/functions.kt) - Definisi dan pemanggilan fungsi dasar.
* [`if expression.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/if%20expression.kt) - Penggunaan `if` sebagai ekspresi yang mengembalikan nilai.
* [`indexing_other.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/indexing_other.kt) - Contoh lain atau lanjutan dari penggunaan indeks pada koleksi/array.
* [`masih contoh.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/masih%20contoh.kt) - File tambahan yang berisi contoh-contoh bervariasi.
* [`math.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/math.kt) - Fungsi dan operasi matematika dasar.
* [`max_min_value.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/max_min_value.kt) - Cara mendapatkan nilai maksimum dan minimum dari tipe data numerik.
* [`named dan default argument.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/named%20dan%20default%20argument.kt) - Penggunaan *named arguments* dan *default arguments* pada fungsi.
* [`nullable.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/nullable.kt) - Konsep null safety di Kotlin dan cara mendeklarasikan tipe nullable.
* [`nullable_akses.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/nullable_akses.kt) - Berbagai cara mengakses properti atau fungsi dari variabel nullable dengan aman.
* [`numbers.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/numbers.kt) - Berbagai tipe data numerik lainnya (seperti `Double`, `Float`, `Long`).
* [`range.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/range.kt) - Penggunaan `range` untuk iterasi dan kondisi.
* [`raw_string.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/raw_string.kt) - Penggunaan Raw String literal (`"""`).
* [`safe calls.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/safe%20calls.kt) - Penggunaan operator `?.` (safe call) dan `?:` (Elvis operator) untuk penanganan null.
* [`var_val.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/var_val.kt) - Perbedaan antara deklarasi variabel `var` (mutable) dan `val` (immutable).
* [`vararg vs array.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/vararg%20vs%20array.kt) - Perbedaan dan penggunaan `vararg` dibandingkan dengan `Array` dalam parameter fungsi.
* [`variable argument.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/variable%20argument.kt) - Penggunaan `vararg` untuk parameter fungsi yang menerima sejumlah argumen variabel.
* [`when expression.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/when%20expression.kt) - Pengganti `switch-case` yang lebih fleksibel di Kotlin.
* [`while & do while.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/while%20&%20do%20while.kt) - Implementasi perulangan `while` dan `do-while`.

### 🧩 **Konsep Object-Oriented Programming (OOP) Lanjutan**

Bagian ini berisi file-file yang berada di dalam folder `oop/`. File-file ini secara khusus membahas konsep-konsep inti dan lanjutan dari Object-Oriented Programming, seperti kelas, objek, pewarisan, polimorfisme, dan lain-lain.

-   **[`oop/`](https://github.com/MENSTRUE/kotlin-dicoding/tree/master/src/oop)**: Direktori utama untuk materi OOP.
    -   **[`new_package/`](https://github.com/MENSTRUE/kotlin-dicoding/tree/master/src/oop/new_package)**: Contoh penggunaan package baru di dalam modul OOP untuk pengorganisasian kode.
        -   [`sayhello.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/new_package/sayhello.kt): (Deskripsi: Kemungkinan fungsi atau kelas yang menampilkan pesan sapaan, contoh sederhana penggunaan package).
    -   [`Abstract class.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/Abstract%20class.kt): Implementasi kelas abstrak dan fungsionalitasnya.
    -   [`Animal_other.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/Animal_other.kt): Contoh lain dari kelas `Animal` atau kelas terkait hewan, mungkin menunjukkan konsep yang berbeda dari `animal.kt`.
    -   [`Interfaces.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/Interfaces.kt): Demonstrasi penggunaan *interface* di Kotlin untuk kontrak perilaku.
    -   [`Property Delegation.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/Property%20Delegation.kt): Contoh implementasi *property delegation* menggunakan kata kunci `by`.
    -   [`animal.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/animal.kt): Definisi dasar kelas `Animal`, mungkin untuk mendemonstrasikan pewarisan atau properti.
    -   [`exception handling.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/exception%20handling.kt): Cara menangani pengecualian (exceptions) menggunakan `try-catch-finally`.
    -   [`exception.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/exception.kt): Contoh dasar tentang bagaimana pengecualian bekerja di Kotlin.
    -   [`extension.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/extension.kt): Implementasi *extension functions* untuk menambahkan fungsionalitas pada kelas yang sudah ada.
    -   [`import dan packages.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/import%20dan%20packages.kt): Penjelasan lebih lanjut tentang penggunaan `import` dan deklarasi `package`.
    -   [`inheritances.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/inheritances.kt): Implementasi dasar dari konsep pewarisan (inheritance) antar kelas.
    -   [`nullable receiver.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/nullable%20receiver.kt): Penanganan *nullable receiver* dalam *extension functions*.
    -   [`overloading.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/overloading.kt): Contoh *method overloading* (fungsi dengan nama yang sama tetapi parameter berbeda).
    -   [`package import.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/package%20import.kt): (Deskripsi: Serupa dengan `import dan packages.kt`, mungkin variasi atau fokus berbeda).
    -   [`primary constractor.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/primary%20constractor.kt): Detail tentang penggunaan dan inisialisasi melalui konstruktor utama.
    -   [`secondary constractor.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/secondary%20constractor.kt): Detail tentang penggunaan dan kasus penggunaan konstruktor sekunder.
    -   [`striing every where.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/striing%20every%20where.kt): (Deskripsi: Mungkin contoh ekstensif penggunaan dan manipulasi String dalam berbagai konteks).
    -   [`superInheritances.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/superInheritances.kt): Penggunaan kata kunci `super` dalam konteks pewarisan untuk memanggil implementasi dari kelas induk.
    -   [`visibility modifiers.kt`](https://github.com/MENSTRUE/kotlin-dicoding/blob/master/src/oop/visibility%20modifiers.kt): Penjelasan tentang modifier visibilitas (`public`, `private`, `protected`, `internal`).

## 🚀 Cara Menjalankan

1.  **Clone repositori ini:**
    ```bash
    git clone [https://github.com/MENSTRUE/kotlin-dicoding.git](https://github.com/MENSTRUE/kotlin-dicoding.git)
    cd kotlin-dicoding
    ```
2.  **Buka di IDE Kotlin:** Impor proyek ini ke lingkungan pengembangan terintegrasi (IDE) seperti IntelliJ IDEA atau Android Studio.
3.  **Jelajahi File:** Buka setiap file `.kt` untuk melihat kode dan komentar yang disediakan.
4.  **Jalankan:** Anda dapat menjalankan file `.kt` yang memiliki fungsi `main()` untuk melihat output atau perilaku kode tersebut.
